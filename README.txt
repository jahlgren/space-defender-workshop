SPACE DEFENDER - WORKSHOP FOR PROGRAMUTVECKLING

1. Packa upp zip-filen.
2. Studerande: öppna mappen workshop-student med VS Code.
3. Starta LiveServer.
4. Skriv din kod i filen student.js.
5. Följ tutorialhaftet (Space_Defender_Workshop.pdf). Spara student.js för varje ändring.
6. Lärare: mappen workshop-teacher innehaller ett fullt spelbart spel.

OBS: Tryck Space för att starta. Nar spelet kör skjuter Space.
Spelmotorn finns i engine.js och ska inte ändras av studeranden.
Allt fungerar lokalt utan internet eller bibliotek.

Startkoden har inga fiender och ingen fungerande spelarkontroll.
Detta ar avsiktligt: studerande programmerar dem sjalva.
